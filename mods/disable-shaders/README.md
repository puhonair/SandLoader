# Disable Shaders

Restores the missing **Disable Shaders** toggle in Sandustry's Video options menu and adds in-game console commands to easily toggle shaders for better performance and a clean retro pixel look.

## Features
- **Video Options Checkbox:** Adds "Disable Shaders" (fully translated into all 23 languages) in Settings -> Video.
- **Instant Effect:** Disables background/sky post-processing filters and shadow raycast stepping.
- **In-Game Console Commands:**
  - `shaders` or `shaders toggle` — toggle shaders on the fly.
  - `shaders on` / `shaders off` — explicitly enable or disable shaders.
