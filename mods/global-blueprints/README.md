# Global Blueprints

Seamlessly synchronizes and preserves your factory blueprints across all save games and new playthroughs.

## The Problem in Vanilla
In vanilla Sandustry, blueprints are stored inside the save data of a single specific world. When you start a new game, your blueprint tab is completely empty.

## What This Mod Does
- **Automatic Sync:** Every blueprint you create or save in any world is instantly added to your permanent Global Blueprint Library.
- **Cross-Save Availability:** When you start a new game or load an existing one, any blueprints from your global collection are automatically available in your Blueprints tab.
- **Persistent Backup:** Stored in global application storage so your designs survive even across game sessions.
- **In-Game Commands:**
  - `blueprints status` — show how many blueprints are in your global library vs your current save.
  - `blueprints sync` — manually trigger a sync between local and global blueprints.
  - `blueprints export` — export all blueprints as a backup string to the console.
